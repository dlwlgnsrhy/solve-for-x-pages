Support

지원 및 데이터 요청

로그인하지 않아도 지원 요청을 남길 수 있습니다. 제출이 저장되면 화면에 접수번호가 표시되며, 회신받을 이메일로 후속 연락을 드립니다.

보낸 메일은 영업일 기준 2일 안에 확인하는 것을 목표로 합니다.

New support ticket

미인증 상태에서도 지원 요청을 남길 수 있습니다

제출하면 저장된 접수번호를 화면에서 확인할 수 있습니다. 비밀번호, 인증 코드, 카드번호, 주민등록번호, API 키는 입력하지 마세요.

메일에 포함해 주세요

  • 사용 중인 제품 또는 페이지 이름
  • 발생한 문제와 기대했던 결과
  • 오류가 발생한 시각과 기기·브라우저 정보
  • 맞춤 소프트웨어 문의라면 접수 ID

계정·데이터 요청

계정 또는 데이터 삭제를 요청할 때는 사용한 제품명과 가입 이메일을 알려주세요. 본인 확인과 보관 의무 확인이 필요한 경우 추가 정보를 요청할 수 있습니다.

민감정보는 보내지 마세요

비밀번호, 인증 코드, 카드번호, 주민등록번호, API 키는 이메일에 적지 마세요. 화면 캡처에도 이런 정보가 보이지 않는지 확인해 주세요.

현재 확인 가능한 범위

접수번호와 문의 내용은 고객 지원 저장소에 기록됩니다. 실시간 장애 상태나 처리 완료를 의미하지 않으며, 운영팀의 확인과 회신이 다음 단계입니다.
