Support

지원 및 데이터 요청

현재 지원 요청은 이메일로 받습니다. 아래 버튼은 메일 앱을 열 뿐 자동 접수나 발송 완료를 뜻하지 않으며, 메일 앱에서 직접 보내기를 눌러야 합니다.

지원 이메일 작성하기

보낸 메일은 영업일 기준 2일 안에 확인하는 것을 목표로 합니다.

메일에 포함해 주세요

  • 사용 중인 제품 또는 페이지 이름
  • 발생한 문제와 기대했던 결과
  • 오류가 발생한 시각과 기기·브라우저 정보
  • 맞춤 소프트웨어 문의라면 접수 ID

계정·데이터 요청

계정 또는 데이터 삭제를 요청할 때는 사용한 제품명과 가입 이메일을 알려주세요. 본인 확인과 보관 의무 확인이 필요한 경우 추가 정보를 요청할 수 있습니다.

민감정보는 보내지 마세요

비밀번호, 인증 코드, 카드번호, 주민등록번호, API 키는 이메일에 적지 마세요. 화면 캡처에도 이런 정보가 보이지 않는지 확인해 주세요.

현재 확인 가능한 범위

이 페이지에는 티켓 저장소나 실시간 장애 상태 연결이 없습니다. 발송 여부는 보낸 편지함에서, 제품의 실제 상태는 회신을 통해 확인해 주세요.
