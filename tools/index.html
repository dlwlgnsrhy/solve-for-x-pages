기술 자산

모든 도구는 브라우저에서 실행됩니다 — 올린 파일은 이 브라우저 안에서만 처리되어 서버로 전송되지 않습니다. 기술자산 8종을 카드별로 사용해 볼 수 있고, 데모 7종은 샘플 파일로 바로 돌려볼 수 있으며, 계산·공유 상태는 링크 하나로 전달됩니다.

  • 수수료·견적 계산기

    매출·인건비를 넣으면 플랫폼 수수료와 견적이 나옵니다 — 같은 계산 상태가 링크로 공유됩니다.

    사용해 보기없음

  • 정산 대사

    플랫폼 정산서와 내 주문·배송 기록을 건별로 대조 — 미정산·무근거정산 후보·값 불일치·중복정산 신호를 브라우저 안에서 확인합니다.

    사용해 보기샘플 다운로드

  • BI Report Kit

    집계한 숫자가 원데이터와 일치하는지 기계가 검증하는 BI 리포트 구조 — 주 합산과 일별 합을 두 경로로 교차 확인합니다.

    사용해 보기샘플 다운로드

  • Cafe24 Sync Kit

    1건의 주문 실패가 전체를 막지 않고 중복 없이 재처리되는 쇼핑몰 주문 동기화 구조 — 주문번호 멱등 키로 중복을 거릅니다.

    사용해 보기샘플 다운로드

  • CSV Validator

    규칙 설정 0 — 어떤 CSV든 중복·형식 혼합·합계 불일치·음수·빈 셀을 브라우저 안에서 자동 감사합니다.

    사용해 보기샘플 다운로드

  • AI Brief Kit

    건 제목+금액으로 분류·수수료 구간·1페이지 제안 초안을 LLM 없이 결정적 규칙으로 — 같은 입력이면 항상 같은 출력입니다.

    사용해 보기샘플 다운로드

  • Integration Reliability Kit

    정상 행을 보존하고 깨진 행만 원인과 함께 분리해 수정한 행만 재처리하는 연동 실패 트리아지 — 일시적/영구/확인 필요 3분류로 나눕니다.

    사용해 보기샘플 다운로드

  • ERP Ledger Kit

    서로 다른 형식의 여러 ERP 전표를 한 장부로 — 차·대변 균형 검증과 전표번호 멱등 키의 중복 업로드 차단을 브라우저 안에서 확인합니다.

    사용해 보기샘플 다운로드
