CSV 데이터 감사 도구

엑셀로 열어 눈으로 훑기 전에, 이 파일에 문제가 숨어 있는지 기계가 먼저 봅니다. 규칙을 설정할 필요 없이 CSV를 올리면 점검이 자동으로 돌고, 확인이 필요한 항목만 골라 보여 줍니다.

올린 파일은 어디로도 전송되지 않습니다

아래 도구는 이 페이지 안에서 그대로 실행됩니다. 계산이 전부 브라우저 안에서 끝나므로 올린 파일의 내용은 어디로도 전송되지 않습니다. 도구 파일 자체에는 외부로 나가는 요청이 하나도 없습니다. 다만 이 사이트 페이지에는 방문 통계가 동작하니, 통신을 완전히 끊고 쓰시려면 도구를 파일로 내려받아 인터넷 연결 없이 여십시오. 그때도 똑같이 동작합니다.

무엇을 자동 점검합니까

  • 중복 행 — 행 전체가 똑같이 반복된 곳을 행 번호와 함께 찾습니다.
  • 열별 형식 혼합 — 한 열 안에 날짜·숫자·텍스트가 섞이면 각각 몇 건인지 알려 줍니다.
  • 합계 행 불일치 — 합계 행이 있으면 데이터에서 다시 합을 계산해 차이를 보여 줍니다.
  • 금액 열의 음수 — 정정인지 환불인지 사람 판단이 필요한 행을 표시합니다.
  • 빈 셀과 전체가 빈 열 — 열별 빈 셀 수를 집계하고, 모두 비어 있는 열을 표시합니다.

지금 사용해 보기

준비된 샘플 CSV가 도구 안에 들어 있어, 내 파일이 없어도 바로 눌러 볼 수 있습니다. 열 이름이나 순서를 맞추실 필요가 없습니다.

화면이 좁게 보이면 새 탭에서 열기를 이용하십시오. 같은 파일입니다.

이 도구가 하지 않는 일

값이 업무적으로 맞는지는 판단하지 않고, 파일을 대신 고쳐 주지도 않습니다. 무엇이 이상한지 알려줄 뿐 고칠지 말지는 사람이 정합니다. 업종별 업무 규칙은 알지 못하는 범용 패턴 점검이며, 데이터베이스나 다른 시스템과 연동하지 않고 올린 CSV만 봅니다. 수만 행 이상의 대용량 파일은 아직 검증하지 않았습니다.

내 컴퓨터에 두고 쓰기

위 도구는 HTML 파일 하나입니다. 파일로 받아 두시면 이 사이트에 들어오지 않아도, 인터넷이 없어도 다음 달에 그대로 다시 쓰실 수 있습니다. 판매 준비는 끝났지만 결제 연결이 아직 남아 있어 지금은 구매 버튼을 열어 두지 않았습니다.
