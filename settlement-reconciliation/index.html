정산 불일치 확인

플랫폼 정산서와 내 주문 기록이 안 맞을 때

이번 달 정산이 내 기록과 다르면, 합계를 다시 더하기 전에 두 파일을 같은 주문번호로 나란히 놓아야 합니다. 아래 도구가 일치·금액 불일치·한쪽에만 있는 건·중복·수수료 차이·정산 일차를 나눠 보여 줍니다.

요약두 파일을 올리면 어느 건이 다른지부터 나옵니다. 어느 쪽이 맞는지 이 도구는 판정하지 않고, 확인해야 할 목록만 남깁니다. 회원가입 없이 무료입니다.

파일 두 개 고르기샘플로 먼저 해 보기 →

샘플로 먼저 해 보려면 도구 화면의 「샘플 CSV 2개 내려받기」 버튼을 누른 뒤 그대로 올리면 됩니다. 내 파일이 없어도 결과가 어떤 모양인지 확인할 수 있습니다.

어떤 상황에서 찾아오시나요

플랫폼에서 받은 정산서(또는 정산내역서)와 갖고 있는 주문·배송 기록의 금액이 안 맞을 때입니다. 매달 같은 비교를 손으로 하고 있고, 합계 차이는 보이는데 어떤 건 때문인지는 알지 못하는 상황입니다.

합계가 다르다는 사실만으로는 원인을 알 수 없습니다. 그래서 이 도구는 합계가 아니라 행 단위로 무엇이 다른지부터 보여 줍니다.

무엇을 얻을 수 있습니까

아래 여섯 가지는 도구가 실제로 계산해서 화면에 그리는 값입니다. 기능 목록이 아니라 출력 항목입니다.

출력 항목무엇을 뜻하는가
일치양쪽에 있고 금액이 같은 건수
값 불일치같은 키인데 금액이 다른 건수. 차이 금액과 함께 표시합니다
첫째 파일에만 / 둘째 파일에만한쪽에만 존재하는 건수. 고른 파일 이름이 그대로 붙습니다
중복(같은 쪽)한 파일 안에서 같은 키가 반복된 건수. 중복정산 신호이며 총액에는 이미 모두 합산돼 있습니다

그 밖에 총액 비교(양쪽 합계와 차이), 대조 불가 행, 확인 필요 항목 건수, 일치 행 체크섬, 결과 CSV 내려받기를 함께 보여 줍니다.

예시 — 아래 결과는 실제 실행 결과입니다

이 숫자는 사람이 만든 가짜 데이터입니다. 실제 사용자 사정이 아닙니다. 실측 절감 시간이나 회수 금액을 제시하지 않습니다.

도구 화면의 「샘플 CSV 2개 내려받기」로 받은 파일을 그대로 올리면 아래와 같이 나옵니다.

입력한 파일

첫 번째 파일두 번째 파일
정산일, 주문번호, 정산금액, 수수료 — 7행발주일, 주문번호, 주문금액, 수수료 — 6행

실행 결과

일치 4 · 값 불일치 1 · 첫째 파일에만 1 · 둘째 파일에만 1
총액 532,000원 / 508,000원 (차이 24,000원)
중복 1건(중복정산 신호) · 수수료 불일치 1 · 일차 3~4일(중간 3.5)

일치 4건은 그대로 맞은 건입니다. 확인 대상은 값 불일치 1건 · 한쪽에만 있는 건 2건 · 같은 쪽 중복 1건으로 4건이고, 금액은 맞는데 수수료만 다른 건이 1건 더 있습니다.

위치유형도구가 출력한 사유
B-1002수수료 불일치금액은 양쪽 모두 85,000원으로 같지만 수수료가 첫째 파일 12,750원(15%), 둘째 파일 8,500원(10%)으로 다릅니다. 총액에는 영향이 없습니다.
B-1003값 불일치첫째 파일 64,000원 ≠ 둘째 파일 68,000원 (차이 -4,000원) — 두 쪽 중 한 쪽이 잘못 입력됐거나 일부만 반영됐습니다.
B-1005첫째 파일에만첫째 파일(47,000원)에만 있고 둘째 파일에 없습니다.
B-1006둘째 파일에만둘째 파일(52,000원)에만 있고 첫째 파일에 없습니다.
B-1007중복(같은 쪽)첫째 파일에서 이 키의 행이 반복 등장 — 총액에는 이미 모두 합산되어 있습니다.

합계 차이 24,000원은 위 다섯 건 가운데 네 건이 만든 것입니다. B-1003 값 불일치 -4,000원, B-1005 첫째 파일에만 +47,000원, B-1006 둘째 파일에만 -52,000원, B-1007 같은 쪽 중복 +33,000원. 합계가 -4,000 + 47,000 - 52,000 + 33,000 = +24,000원입니다. B-1002 수수료 불일치는 수수료 열의 차이여서 이 합계에 들어 있지 않습니다.

한쪽에만 있는 건은 하나씩은 총액에 그대로 더해집니다. 하지만 같은 기간에 반대 방향으로 한 건씩 있으면 서로 상쇄될 수 있습니다. 위 표에서도 첫째 파일에만 47,000원과 둘째 파일에만 52,000원이 만나 순으로는 -5,000원만 남습니다. 그래서 합계가 맞아도 누락은 있을 수 있습니다. 이 도구는 어느 쪽이 맞는지 말하지 않습니다. 위 분류는 두 파일의 차이만으로 한 것이고, 계약서나 플랫폼 문서 확인은 사람이 해야 합니다. 이 상쇄가 왜 문제인지는누락 확인 페이지에서 다룹니다.

어떤 파일을 올려야 합니까

두 파일 모두 공통 키 열과 금액 열이 있어야 합니다. 이 두 열은 부분 문자열로 찾습니다 — 아래 문자열이 열 이름에 들어 있으면 후보로 찾습니다. 수수료·날짜 열도 부분 문자열로 찾으므로, 결과가 사용할 열과 맞는지 원본 헤더를 확인하십시오.

공통 키 열주문번호 · 건번호 · 공통키 · 상품코드 · 레코드번호 · key · id · common_key · no
금액 열정산금액 · 주문금액 · 금액 · 총액 · 순액 · 순이익 · 순매출 · 차액 · 값 · amount · value · total
있으면 함께 보고수수료 열 — 수수료 · 수수료액 · fee · fee_amount / 날짜 열 — 정산일 · 발주일 · 날짜 · 일시 · date

금액 열의 뜻은 이름만으로도 대부분 읽힙니다. 정산금액·주문금액 은 건별 정산액이고총액 은 그 파일의 합계이며 순액 은 입금에서 출금을 뺀 값입니다. 고른 열 이름과 그 뜻은 실행 화면과 결과 화면 양쪽에 그대로 나옵니다.

인코딩은 UTF-8(BOM 포함) · EUC-KR/CP949 · UTF-16 을 자동으로 읽고, 구분자도 자동으로 판정합니다.

금액 열이 둘 이상이면 — 직접 골라야 합니다

어떤 파일은 금액처럼 보이는 열이 둘입니다. 예를 들어 통장 내역에 입금액과 출금액이 함께 들어 있는 경우입니다. 이 도구는 그럴 때 대신 골라 버리지 않습니다.

  1. 실행 전에 두 파일에서 사용할 공통 키 열과 금액 열을 화면에 보여 줍니다.
  2. 후보가 둘 이상이면 실행 버튼이 눌리지 않습니다. 직접 고른 뒤에 실행합니다.
  3. 고른 열 이름은 실행 화면과 결과 화면 양쪽에 그대로 나옵니다.
  4. 잘못 골랐다면 열을 다시 고르고 다시 실행하면 됩니다.

순액을 비교하고 싶다면 순액 열이 들어 있는 파일을 올리십시오. 이 도구는 입금액에서 출금액을 빼서 순액을 만들어 주지 않습니다. 빈 칸이 섞인 채로 계산하면 조용히 틀린 값이 나오기 때문입니다.

이 도구가 하지 않는 일

  • 어느 쪽이 맞는지 판정하지 않습니다. 차이가 났다는 사실까지만 말합니다.
  • 두 파일 어디에도 없는 거래는 찾지 못습니다. 대조는 두 파일에 있는 것끼리만 붙입니다. 한쪽에만 있는 거래는 「첫째 파일에만 / 둘째 파일에만」 항목으로 보고합니다.
  • 플랫폼 API와 연동하지 않습니다. 정산서와 기록을 직접 내보내야 합니다.
  • 수수료율이 계약과 맞는지 판정하지 않습니다. 차이만 보여줍니다.
  • 정산 주기를 자동으로 감시하지 않습니다. 실행은 사람이 누를 때만 됩니다.
  • 일차에 기준선을 두지 않습니다. 최소·중간·최대만 보고합니다.
  • 대용량 파일의 처리량을 검증하지 않았습니다. 수만 행은 확인하지 않았습니다.
  • 결과는 회계·세무 판정이 아닙니다. 확인 목록을 만들어 주는 도구입니다.

이 도구로 답이 안 나오는 경우

  • 공통 키 열이나 금액 열을 찾지 못한 경우 — 대조하지 않고 어느 파일의 어느 열이 없는지 먼저 알려 줍니다. 열 이름을 아래 목록에 맞춰 다시 내려보내세요.
  • 파일을 하나만 고른 경우 — 대조에는 두 쪽이 모두 필요합니다.
  • 키가 비어 있거나 금액을 숫자로 읽을 수 없는 행 — 대조에서 제외하고 확인 필요 목록에 남깁니다.
  • 거래가 서로 다른 형식일 때(정산서와 통장 내역처럼 키가 없는 파일) — 이 도구는 키 열이 없으면 대조하지 않습니다.

공통 키 없이 비교해야 한다면 정산 대사 데모를 보십시오. 날짜와 금액을 기준으로 다섯 단계로 맞춰 보는 다른 방식입니다. 비교 기준이 다르니 결과도 다릅니다.

자주 묻는 질문

그냥 올려도 되나요?

네. 회원가입도, 메일 입력도 없습니다. 결과는 브라우저 안에서만 계산됩니다.

파일이 밖으로 나가지나요?

계산과 결과 표시가 전부 이 기기 안에서 끝납니다. 다만 이 문장만으로 도구를 고르지 마십시오. 같은 문장을 쓰는 다른 도구도 여러 곳에서 확인했습니다. 고르는 기준은 이 도구가 하지 않는 일과 답이 안 나오는 경우가 분명한지입니다.

무료인가요?

도구 실행에는 회원가입도 비용도 없습니다. 다만 반복해서 하는 이 일을 대신 해 주는 서비스의 범위는 별도이며, 그 가격은 이 페이지에 고정해서 적지 않습니다.

오류를 찾아서 고쳐주나요?

아니요. 알려만 줍니다. 파일을 고쳐 쓰거나 다시 만들어 주지 않습니다. 판정은 사람이 합니다.

정산이 자동으로 맞게 되나요?

아니요. 이 도구는 정산 데이터를 바꾸지 않습니다. 어디가 불일치한지 확인하는 목록을 만드는 도구입니다.

이렇게 하면 문의하면 되는 경우

  • 같은 비교를 매달 반복하고 있고 수작업으로 정리하고 있다
  • 두 파일의 형식이 매번 달라서 대조가 자주 막힌다
  • 이 도구가 다루지 않는 형식(세금계산서·ERP·재고)이라 방법을 함께 정하고 싶다

도구 화면에 문의 버튼이 없을 수 있습니다. 그럴 때는 이 페이지의 「범위 확인부터 시작하기」를 누르십시오. 문제는 한 문장으로 적어 주시면 됩니다.

근거와 한계. 이 페이지의 예시 결과는 /tools/settlement-reconcile 도구에서 그 화면 안의 샘플 파일을 직접 실행한 결과입니다 (확인 2026-10-03). 열 선택 동작과 실패 처리는 합성 입력 13종으로 확인했습니다. 실제 사용자 파일 형식과 대용량 파일은 검증하지 않았습니다. 같은 이름의 /demos/settlement-reconcile/ 은 다른 알고리즘이므로 같은 파일을 올려도 다른 결과가 나옵니다. 도구 결과는 회계·세무 판정이 아닙니다.
