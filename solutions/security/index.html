해결하는 문제

이미 쓰시는 Microsoft 365로, 보안 점검에 답할 기록을 남깁니다

  • 거래처·원청의 보안 점검을 받는 회사"PC 암호화, 화면 잠금, USB 통제 되어 있나요?"에 기록으로 답합니다
  • 학원·쇼핑몰처럼 고객 개인정보를 다루는 회사노트북을 잃어버린 날에 쓸 기록 — 다음 단계

저희 프로그램을 PC에 설치하지 않습니다. (PC는 Intune에 등록되어 있어야 합니다)

시연할 수 있는 것
Microsoft 읽기 전용 연결, 연결 직후 진단, 기준 묶음 미리보기, 변경 제안 → 휴대폰 승인 → 시범 그룹 실행 → 되돌리기, 고쳐지면 드러나는 변경 기록(이어짐 확인)
보안 검토
연결·승인·실행 부분은 만든 AI 모델과 다른 AI 모델 두 가지로 각각 코드 보안 검토를 했습니다(외부 기관의 감사·인증은 아닙니다)

실제 Microsoft 365 환경 연결 시험, 실제 장비 실측 기록, 분실 대응 기록서, 점검 항목별 보고서

사내 통합 로그인(SSO)을 쓰는 회사를 위한

사내 2차 인증

직원 확인 흐름 시연 가능 · 설계 상담 신청 가능

해결하는 문제

비밀번호 하나가 새면, 그대로 업무 시스템에 들어올 수 있습니다

바깥 인증 서비스에 연결하기 어려운 회사도, 업무 시스템 로그인 뒤에 OTP 앱으로 한 번 더 확인할 수 있어야 합니다.

회사 서버 안에 설치하는 방식입니다.

지금 할 수 있는 것

준비된 것
부서·직급·사내망/외부망에 따라 2차 확인을 거는 정책 판단, 업무 시스템이 부르는 연동 API, 직원 화면(인증 앱 등록·6자리 확인·복구 코드·연속 실패 잠금)
보안 검토
업무 시스템 연동과 직원 화면은 만든 AI 모델과 다른 AI 모델로 코드 보안 검토를 했고, 지적을 고치거나 다음 단계(관리 화면)로 넘긴 뒤 다시 확인했습니다(외부 기관의 감사·인증은 아닙니다).
다음 단계
관리 화면, 감사 기록 내려받기, 연동 예시

업무 시스템 로그인 방식(SSO 종류)을 알려 주시면, 회사 서버 안 설치 방식으로 맞출 수 있는지 먼저 봐 드립니다.
