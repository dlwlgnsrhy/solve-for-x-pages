거래장

도매 주문·재고·출고·미수 관리

엑셀과 메신저로 받던 도매 주문을 거래처 주문부터 재고·피킹·거래명세서·미수금·월 마감까지 한 흐름으로 잇는 도매 회사용 업무 앱입니다. 관리자·창고·거래처가 자기 화면만 봅니다.

웹에서 열기App StoreGoogle Play

시연 영상

예시 데이터로 찍은 실제 화면입니다 · 61초.

한 흐름

매입 → 입고 → 재고 → 거래처 주문 → 승인(재고 예약) → 피킹·출고 → 거래명세서 → 입금 → 월 마감

  1. 거래처 주문과 승인거래처는 자기 단가로 주문하고 재고 부족을 바로 봅니다. 관리자가 승인하면 재고가 예약되고, 모자란 주문은 줄별 부족 표와 함께 막힙니다.
  2. 재고와 피킹SKU별 현재고·예약·가용을 색상×사이즈 격자로 봅니다. 창고는 휴대폰에서 피킹·부분 출고를 확정합니다.
  3. 거래명세서와 미수출고하면 거래명세서가 만들어지고, 명세서별 미수금과 30·60·90일 경과를 봅니다.
  4. 월 정산과 마감거래처별 월 정산표로 마감합니다. 마감한 달의 출고·입금·조정은 바꿀 수 없습니다.

핵심 화면

모든 화면은 실제 앱을 시연 데이터로 띄워 찍은 것입니다(웹 · 휴대폰 앱).

역할마다 자기 화면

관리자
상품·단가·거래처, 매입·주문 승인, 입금, 월 정산·마감
창고
입고·피킹·출고, 재고 조회·조정 요청 (금액은 안 보임)
거래처
자기 단가로 주문, 자기 주문·명세서·미수 보기

이런 곳에 맞습니다

  • 색상·사이즈·포장 단위 조합이 많은 의류·잡화·식자재 도매
  • 거래처마다 단가가 다른 회사
  • 메신저로 주문 받고 장부로 재고를 보는 회사
  • 월말 명세서·미수·입금 맞추기에 시간이 드는 회사

안전하게

  • 모든 계정 2단계 인증
  • 거래처 담당자 연락처는 암호화 저장
  • 마감한 달은 코드와 DB 둘 다에서 변경 거절
