현장온

현장 접수·견적·일정·기록 관리

전화 접수부터 견적·기사 배정·현장 기록·서명·청구·입금까지 한 줄로 잇는 현장 출동 회사용 업무 앱입니다. 사무실은 웹에서, 기사는 휴대폰에서 같은 건을 봅니다.

시연 영상

예시 데이터로 찍은 실제 화면입니다 · 76초.

한 흐름

접수 → 견적 → 고객 승인 → 기사 배정 → 현장 기록 → 완료 → 청구 → 입금

  1. 접수와 견적단가표에서 항목을 골라 견적을 쓰면 공급가·부가세·합계를 서버가 계산합니다. 견적은 판으로 남고, 보낸 판은 고치지 않습니다.
  2. 배정과 일정같은 기사·같은 시간에 겹치게 배정하면 겹친 건을 보여 주고 거절합니다. 기사는 휴대폰에서 오늘·주간 일정을 봅니다.
  3. 현장 기록체크리스트·작업 전후 사진·고객 서명을 현장에서 받고, 완료 보고서가 바로 만들어집니다.
  4. 청구와 입금승인 견적과 같은 금액으로 청구서를 만들고, 나눠 받은 입금까지 기록해 미수·연체를 한눈에 봅니다.

핵심 화면

모든 화면은 실제 앱을 시연 데이터로 띄워 찍은 것입니다(웹 · 휴대폰 앱).
