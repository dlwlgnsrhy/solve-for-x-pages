데이터 삭제 안내 (Data Deletion Guide)

1. 데이터 저장 방식

SFX Imjong Care(임종케어)는 사용자가 작성하는 모든 유언장(Wills) 및 관련 텍스트를 사용자의 모바일 기기 내부(SharedPreferences, SecureStorage)에만 로컬 저장합니다.

외부 서버로 데이터를 전송하지 않는 "Zero-Server" 아키텍처이므로, 서버측에는 삭제할 사용자 데이터가 존재하지 않습니다.

2. 앱 내 데이터 초기화 방법

앱 내 설정(Settings) 메뉴에서 "데이터 초기화" 또는 "모든 유언장 삭제" 옵션을 통해 저장된 모든 로컬 데이터를 즉시 폐기할 수 있습니다.

초기화 시 SecureStorage 내 암호화 키까지 함께 제거되어 복구가 불가능합니다.

3. 앱 삭제(Uninstall)

iOS/Android에서 앱을 삭제(Uninstall)하면 기기에 저장된 모든 유언장 데이터와 암호화 키가 운영체제 정책에 따라 함께 삭제됩니다.

별도의 계정 시스템이 없으므로 별도 회원 탈퇴 절차는 필요하지 않습니다.

4. 문의

데이터 삭제 관련 문의는 soluni@solve-for-x.net 으로 연락 주시기 바랍니다.
