최종 사용자 라이선스 계약 (EULA)

1. 서비스 목적

Solve for X는 고객이 맞춤 소프트웨어 제작 상담을 신청하고, soluni가 요청을 검토하기 위한 접수 앱입니다.

앱은 상담 접수와 상태 확인을 제공하며, 앱 내 결제, 유료 디지털 콘텐츠 판매, 자동 착수 보장을 제공하지 않습니다.

2. 사용자 책임

사용자는 본인이 제공할 권한이 있는 정보만 입력해야 하며, 비밀번호, API key, 카드번호, 타인의 민감정보 또는 불법적 의뢰 내용을 제출해서는 안 됩니다.

의료, 법률, 금융, 자해/위기, 미성년자 개인정보 등 고위험 요청은 자동 진행되지 않고 별도 검토가 필요합니다.

3. 착수 및 비용

앱에 표시되는 패키지와 가격은 상담 범위를 이해하기 위한 안내이며, 실제 착수와 비용은 soluni가 제안서를 보낸 뒤 고객과 수동으로 확인합니다.

스토어 앱 내에서 결제 버튼이나 외부 결제 링크를 제공하지 않습니다.

4. 면책

soluni는 모든 요청을 수락하거나 특정 기간 내 납품을 보장하지 않습니다. 프로젝트 진행 가능 여부는 문제 범위, 위험도, 기술 가능성, 운영 리소스에 따라 결정됩니다.
