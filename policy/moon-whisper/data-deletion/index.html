데이터 삭제 안내 (Data Deletion Guide)

개인정보 처리방침이용약관데이터 삭제 안내

1. 앱에서 지우는 방법 (가장 빠르고 확실합니다)

달님에게를 열고 나 > 설정 > 계정과 모든 데이터 삭제로 들어갑니다.

지울 곳을 고릅니다: 서버에 저장된 데이터 / 클라우드 백업(Google Drive 또는 iCloud) / 이 기기.

확인 창에서 삭제를 누르면 끝납니다. 서버가 정리 중이면 안내가 나오고 같은 화면에서 다시 시도할 수 있습니다.

2. 지워지는 것

서버: 일기(꾸미기 정보 포함), 미래 일기, 클라우드 설정, 프로필, 달님 호출 기록, 광장에 올린 글·댓글·반응·팔로우·차단·신고 내역.

이 기기: 일기·미래 일기·녹음 파일·예약된 알림·앱 설정.

클라우드 백업: Google Drive와 iCloud의 달님에게 백업 파일(삭제를 선택하고 해당 계정에 로그인되어 있을 때).

3. 지워지지 않거나 시간이 걸리는 것

결제 기록: App Store·Google Play·RevenueCat의 구매 내역은 각 회사와 법령에 따라 보관되며 앱이 지울 수 없습니다. 구독은 스토어 설정에서 직접 해지해야 합니다(계정을 지워도 자동 해지되지 않습니다).

서버 백업과 로그: 서버 데이터는 즉시 지워지고, 데이터베이스 백업본은 약 7일, 운영 로그(일기 본문 없음)는 약 30일이 지나면 사라집니다.

다른 사용자에게 이미 공개되어 저장·캡처된 내용은 지울 수 없습니다.

본문이 없는 안전 조치 집계(조치 종류·시각·월별 건수)와, 처리 중인 긴급 안전 건의 최소 정보(최대 7일)는 개인정보 처리방침에 적힌 대로 보관 후 파기합니다.

4. 앱을 쓸 수 없을 때

앱을 삭제했거나 기기를 잃어버렸다면 soluni@solve-for-x.net 으로 제목 "달님에게 데이터 삭제 요청", 사용하던 기기 종류, 대략 사용한 기간, 구독 여부를 보내 주세요.

달님에게는 가입 없이 익명으로도 쓸 수 있어, 익명 계정은 이메일만으로 어느 데이터가 본인 것인지 확인할 수 없습니다. 이 경우 앱을 다시 설치해 같은 기기·같은 계정으로 로그인한 상태에서 앱 안 삭제를 이용해 주세요. Google·Apple 계정을 연결해 둔 경우 그 계정 이메일로 요청하시면 본인 확인 후 영업일 7일 안에 처리하고 결과를 회신합니다.

일기 내용을 이메일로 보내지 마세요. 삭제에 필요하지 않습니다.
