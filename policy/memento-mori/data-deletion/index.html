데이터 삭제 안내 (Data Deletion Guide)

개인정보 처리방침이용약관데이터 삭제 안내

1. 데이터 저장 방식

SFX Memento Mori(메멘토 모리)는 생년월일과 목표 수명 등의 입력 데이터를 오직 사용자 기기의 Local SharedPreferences에만 저장합니다.

외부 서버로 어떤 개인 데이터도 전송되지 않으므로, 서버측에는 삭제할 사용자 데이터가 존재하지 않습니다.

2. 앱 내 데이터 초기화 방법

앱 내 설정(Settings) 메뉴에서 "데이터 초기화" 옵션을 선택하면 생년월일 및 그리드 렌더링 관련 로컬 데이터가 즉시 삭제됩니다.

초기화 후에는 앱을 재실행하면 최초 온보딩 상태로 복귀합니다.

3. 앱 삭제(Uninstall)

iOS/Android에서 앱을 삭제하면 기기 내에 저장된 모든 로컬 데이터가 운영체제 정책에 따라 함께 제거됩니다.

별도의 계정 시스템이 없으므로 별도 회원 탈퇴 절차는 필요하지 않습니다.

4. 문의

데이터 삭제 관련 문의는 soluni@solve-for-x.net 으로 연락 주시기 바랍니다.
