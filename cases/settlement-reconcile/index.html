Settlement Reconcile Web Service

플랫폼 정산서가 내 기록과 한 건 한 건 정말로 같은 금액인지, 누락·중복·수수료 차이가 없는지를 전수 대조해야 하는 문제

지금 상태
공개 데모에서 직접 올린 파일로 확인 가능플랫폼 정산서와 내 주문/배송 기록을 두 경로로 올릴 수 있습니다 — ① 각 파일 1개씩(날짜·금액 열을 직접 매핑, 5단계 날짜·금액 대조: 전일치→정산 주기→수수료 차감→미분류→누락) ② 소스(두 쪽의 실제 이름)·공통 키·금액 세 열로 하나의 CSV로 합친 파일(공통 키 조인: 일치·값 불일치(차이 표시)·한쪽만 존재(미정산·무근거정산 후보)·같은 쪽 중복(중복정산 신호)). 수수료 열이 있으면 수수료 불일치를, 날짜 열이 있으면 정산-발주 일차 분포(최소~최대·중간)와 총액 차이를 브라우저 안에서 보여 줍니다. EUC-KR(엑셀 인코딩) 파일은 인코딩 자동 감지로 그대로 처리합니다. 파일은 서버로 전송되지 않습니다.

누구를 위해, 어떻게

이 제품을 찾는 사람
마켓플레이스·PG·위탁 운영 등 정산서와 자체 기록을 따로 두는 운영·회계 팀
처음부터 신경 쓴 점
실제 플랫폼 API 연동 없이 내 파일로 검증해야 하고, 플랫폼의 수수료율 규칙이나 정산 주기 임계값을 사전에 설정하지 않으며, 샘플 결과를 고객 성과로 말하지 않습니다.
고른 해결 방법
두 입력 경로를 하나의 정산 대조 엔진(브라우저 로컬, 서버 0)에서 판정합니다. ① 두 파일 경로: 각 파일을 1개씩 올려 날짜·금액 열을 직접 매핑하면 5단계 날짜·금액 대조(전일치 → 정산 주기(날짜 이동 1~3일) → 수수료율 일치(수수료 차감) → 미분류 → 한쪽만 존재)를 돌려 원인과 차액까지 표시합니다. ② 한 파일 경로: 소스 열(두 쪽의 실제 이름, 예: 정산서/주문)·공통 키·금액을 가진 단일 CSV를 공통 키로 조인해 일치·값 불일치(차이 표시)·한쪽만 존재(미정산·무근거정산 후보)로 분류합니다. 두 경로 모두 같은 쪽에서 키(또는 날짜·금액)가 반복되면 중복정산 신호로 표시합니다(총액은 모든 행을 합산해 차이에 그대로 드러나게 둠). 옵션 수수료 열의 키별 차이와 옵션 날짜 열의 일차 분포(임계값 없음)를 보고하고, 일치 행으로 순서 무관 체크섬을 계산해 대조 결과를 CSV로 내보냅니다.

만든 것

  • 브라우저 전용 정산 대조기(서버 전송 0)
  • 2파일(열 매핑, 5단계 날짜·금액 대조) + 1파일(소스 열, 공통 키 조인) 두 경로 — 단일 엔진
  • 중복정산 신호(같은 쪽 키·날짜·금액 반복) — 총액에 포함
  • 수수료 불일치 + 정산-발주 일차 분포(옵션 열)
  • EUC-KR/UTF-8/UTF-16 인코딩 자동 감지(브라우저 파서)
  • 총액 차이와 순서 무관 체크섬, 대조 결과 CSV

확인한 것

공개 사이트에서 데모를 열고, 정산서와 내 기록을 두 파일(각각 열 매핑) 또는 합친 CSV(소스 열)로 올려 대조를 돌려본 뒤 대조 결과 CSV를 내려받을 수 있습니다.

  1. 확인됨

    직접 파일 왕복(1파일 경로)

    샘플 입력 CSV 9행을 올리면 일치 2, 값 불일치 1(차이 20,000원), 정산서만 1, 주문만 1, 중복 1(중복정산 신호), 수수료 불일치 1건을 찾아내는 것을 테스트로 통과했습니다.

  2. 확인됨

    직접 파일 왕복(2파일 경로)

    EUC-KR·BOM 샘플 2종(은행 내역·정산 내역, 각 6행)을 인코딩 자동 감지로 읽어 5단계 대조(일치 3, 날짜 이동 1, 수수료 차감 1, 미분류 1 — 차이 1,240,000원)를 판정하는 것을 테스트로 통과했습니다.

  3. 확인됨

    총액 차이 계산

    샘플에서 총액 정산서 640,000원 / 주문 470,000원(차이 170,000원)을 판정하는 것을 — 중복 행이 총액에 포함돼 차이로 드러나는 것을 포함해 — 테스트로 통과했습니다.

  4. 확인됨

    일차 분포 + 순서 무관 체크섬

    샘플에서 정산-발주 일차 3~4일(중간 3.5)을 보고하는 것과, 같은 데이터가 어떤 순서로 와도 일치 행 체크섬이 같은 값을 내는 것을 테스트로 통과했습니다.

  5. 확인 중

    고객 성과

    실제 고객의 정산 대조 시간 단축은 아직 측정하지 않았습니다.

화면

쓰기 전에 알아 둘 점

올린 CSV는 이 브라우저 안에서만 처리되어 서버로 전송되지 않습니다. 공개 데모의 샘플은 키·금액·수수료·날짜만 사용하는 가상 데이터입니다.

  • 어느 쪽이 옳은지는 판정하지 않습니다 — 한쪽만 존재·중복·값 불일치 행을 골라 사람이 결정해야 할 곳만 표시하는 도구입니다.
  • 수수료율 계약 검증(“이 수수료율이 계약과 맞는가”)과 정산 주기 임계값 판단은 하지 않습니다 — 수수료·일차 차이와 분포만 보고하는 것이 이 도구의 한계입니다.
  • 브라우저에서 두 파일(열 매핑) 또는 파일 하나(두 쪽을 합친 형태)를 올리는 검증 도구이며, 실제 플랫폼 API 연동·정산 스케줄·수만 행 이상 파일 처리량은 검증하지 않았습니다.
