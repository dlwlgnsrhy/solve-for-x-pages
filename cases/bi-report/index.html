매출·거래 리포트가 수작업으로 나뉘다 보니 대시보드의 합이 원데이터와 어긋나고, ‘숫자가 맞지 않는다’는 말이 먼저 나오는 문제

현재 상태 · 브라우저 직접 파일 실행 기능 반영 · 공개 데모에서 확인
공개 데모에서 직접 올린 파일로 확인 가능

내 거래 CSV를 올리면 일별·주별 집계를 계산하고, 주 합산이 원데이터와 일치하는지 두 계산 경로로 교차 확인합니다. Looker용 CSV도 내려받을 수 있습니다. 파일은 서버로 전송되지 않습니다.

내 거래 파일로 바로 돌려보기 ↗

어떤 사람을 위해 만들었나요?

이 제품을 찾는 사람: POS·SCM·쇼핑몰 데이터로 일별·주별 리포트를 보는 소규모 운영·마케팅 팀

처음부터 신경 쓴 점: 실제 POS·SCM 접속 없이 내 파일로 검증해야 하고, 컬럼명을 고정 스키마에 종속시키며 샘플 합을 고객 매출 성과로 말하지 않습니다.

우리가 고른 해결 방법: 업로드된 거래 CSV를 브라우저 안에서만 파싱해 일별로 집계하고, 주 합산은 일별 행이 아니라 원행에서 다시 계산해 두 경로가 일치하는지 교차 확인합니다. 날짜·컬럼명은 별칭으로 받아 내 파일의 표기도 그대로 인식합니다.

무엇을 만들었나요?

  • 브라우저 전용 거래 CSV 집계 검증기(서버 전송 0)
  • 일별·주별(ISO 주) 집계와 총액 계산
  • 주 합산 vs 원행 재계산 교차검증
  • Looker Studio용 고정 헤더 CSV 출력

지금 확인할 수 있는 것

사용 전에 알아둘 점

올린 CSV는 이 브라우저 안에서만 처리되어 서버로 전송되지 않습니다. 공개 데모의 샘플은 날짜·금액만 사용하는 가상 데이터입니다.

  • 브라우저에서 파일 하나를 올리는 검증 도구이며, 실제 POS·SCM 실시간 연결·처리량은 검증하지 않았습니다.
  • 집계 규칙은 ‘날짜 열 1개 + 금액 열 1개’ 기준으로, 여러 금액 열을 가진 파일은 첫 매칭 열만 계산합니다.
  • 고객의 실제 매출·성과 수치는 이 데모에 포함하지 않습니다.
