AI Brief Web Service

제안·과제가 들어오면 ‘이건 우리 일인가, 얼마 규모인가, 받아도 되는 선인가’를 사람 기억과 경험으로 판단해야 하는 문제

지금 상태
공개 데모에서 직접 올린 파일로 확인 가능내 제안·과제 CSV를 올리면 LLM 없이 규칙 엔진만으로 카테고리(ERP·연동·BI·EC·AI)와 수수료 구간(10/15/20%)을 분류하고, 500만 원 미만에는 NO-BID 경고를 붙입니다. 같은 파일이면 언제나 같은 결과입니다. 파일은 서버로 전송되지 않습니다.
단계
브라우저 직접 파일 실행 기능 반영 · 공개 데모에서 확인
직접 확인
내 제안 리스트로 바로 돌려보기 ↗

누구를 위해, 어떻게

이 제품을 찾는 사람
위시켓·입찰·제안 관리를 하는 소규모 개발·컨설팅 팀
처음부터 신경 쓴 점
고객 제안 내용 전체를 서버로 보내는 방식이 아니라 내 파일로 검증해야 하고, LLM의 랜덤성을 제품 행위에 섞지 않으며, 샘플 분류를 실제 수락 성과로 말하지 않습니다.
고른 해결 방법
업로드된 제안 CSV를 브라우저 안에서만 처리해, 팀의 고정 키워드 규칙으로 카테고리를 정하고(우선순위 ERP > 연동 > BI > EC > AI), 금액 구간으로 수수료(10/15/20%)를 매깁니다. 500만 원 미만은 NO-BID 경고를 붙여 수락 경계를 화면으로 확인합니다. LLM을 사용하지 않습니다 — 같은 입력이면 항상 같은 출력입니다.

만든 것

  • 브라우저 전용 제안 분류기(서버 전송 0, LLM 미사용)
  • 키워드 규칙 기반 카테고리 분류(우선순위 고정)
  • 게시액 구간별 수수료 10/15/20% 산출
  • 500만 원 미만 NO-BID 경고와 행별 분류 CSV

확인한 것

공개 사이트에서 데모를 열고, 내 제안 리스트를 올려 돌려본 뒤 행별 분류 CSV를 내려받을 수 있습니다.

  1. 확인됨

    직접 파일 왕복

    샘플 입력 CSV 7행을 올리면 6건 분류(ERP 1 · 연동 2 · BI 1 · AI 1 · 기타 1), NO-BID 2건, 금액 오류 1건이 분리되는 것을 테스트로 통과했습니다.

  2. 확인됨

    결정적 출력

    LLM 없이 같은 파일을 두 번 돌려 결과가 완전히 동일한 것을 테스트로 통과했습니다.

  3. 확인됨

    우선순위·구간 규칙

    ERP와 연동 키워드가 함께 있으면 ERP로, 500만 원 미만이면 20% 구간+NO-BID로 판정하는 것을 테스트로 통과했습니다.

  4. 확인 중

    고객 성과

    실제 제안 채택률·수주액은 아직 측정하지 않았습니다.

화면

쓰기 전에 알아 둘 점

올린 CSV는 이 브라우저 안에서만 처리되어 서버로 전송되지 않고, LLM에도 보내지지 않습니다. 공개 데모의 샘플은 제목·금액만 사용하는 가상 데이터입니다.

  • 분류·수수료 규칙은 팀의 현재 기준(키워드 목록, 500만/1천만 원 구간)을 반영하며, 기준이 바뀌면 규칙만 바뀝니다 — LLM을 쓰지 않아 기준 변경 전후 비교가 쉬워집니다.
  • 분류 어휘는 팀의 고정 키워드이고, 제안 제목에 키워드가 없으면 ‘기타’로 떨어집니다 — ‘기타’ 행은 사람이 제목을 다시 봐야 하는 표시입니다.
  • 브라우저에서 파일 하나를 올리는 검증 도구이며, 실제 입찰·수주 성과는 이 데모로 검증하지 않습니다.
