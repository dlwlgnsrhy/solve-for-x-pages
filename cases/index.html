    BI Report Web Service

    매출·거래 리포트가 수작업으로 나뉘다 보니 대시보드의 합이 원데이터와 어긋나고, ‘숫자가 맞지 않는다’는 말이 먼저 나오는 문제

    내 거래 CSV를 올리면 일별·주별 집계를 계산하고, 주 합산이 원데이터와 일치하는지 두 계산 경로로 교차 확인합니다. Looker용 CSV도 내려받을 수 있습니다. 파일은 서버로 전송되지 않습니다.

  4. 브라우저 직접 파일 실행 기능 반영 · 공개 데모에서 확인●공개 데모에서 직접 올린 파일로 확인 가능

    Integration Reliability Web Service

    ERP·API·파일 연동에서 실패 행이 섞이면, 어떤 건을 그냥 다시 돌리면 되고 어떤 건은 코드를 고쳐야 하는지가 시스템마다 달라 사람이 매번 판단해야 하는 문제

    내 연동 시스템의 실패 로그 CSV를 올리면 어떤 건이 재처리 가능하고 어떤 건은 데이터를 고쳐야 하는지 브라우저 안에서 분류합니다. 범용 규칙에 없는 코드는 ‘확인 필요’로 정직하게 분리합니다. 파일은 서버로 전송되지 않습니다.

    확인됨 · 샘플 입력 CSV 8행을 올리면 6건 분류(재처리 가능 3 · 불가 2 · 확인 1), 중복 1건 제외, 코드 누락 1건 분리되는 것을 테스트로 통과했습니다.

    내 제안·과제 CSV를 올리면 LLM 없이 규칙 엔진만으로 카테고리(ERP·연동·BI·EC·AI)와 수수료 구간(10/15/20%)을 분류하고, 500만 원 미만에는 NO-BID 경고를 붙입니다. 같은 파일이면 언제나 같은 결과입니다. 파일은 서버로 전송되지 않습니다.

  6. 브라우저 자동 감사 도구 · 공개 데모에서 확인●공개 데모에서 직접 올린 파일로 확인 가능

    CSV Validator Web Service

    어떤 CSV든 규칙 설정 없이 올리면 중복 행, 열당 형식 혼합, 합계 행 불일치, 금액 열의 음수, 빈 셀을 브라우저 안에서 자동 감사합니다. 문제만 골라 행 번호와 근거까지 보여 줍니다. 파일은 서버로 전송되지 않습니다.

    확인됨 · 샘플 입력 CSV 7행을 올리면 중복 1, 형식 혼합, 합계 불일치 2(차이 표시), 음수 1건을 찾아내는 것을 테스트로 통과했습니다.

  7. 브라우저 대조 도구 · 공개 데모에서 확인●공개 데모에서 직접 올린 파일로 확인 가능

    Two File Reconcile Web Service

    두 시스템이 같은 일을 말했다고 해도 한 건 한 건 정말로 같은 금액인지, 한쪽에만 있는 행이 있는지를 전수 대조해야 하는 문제

    A·B 두 시스템의 내보내기를 소스(A/B)·공통 키·금액 세 열로 하나의 CSV로 합쳐 올리면, 공통 키 조인으로 일치·값 불일치(차이 표시)·A에만·B에만 존재를 골라내고 총액 차이와 순서 무관 체크섬을 브라우저 안에서 보여 줍니다. 파일은 서버로 전송되지 않습니다.

    확인됨 · 샘플 입력 CSV 8행을 올리면 일치 1, 값 불일치 1(차이 20,000원), A만 1, B만 1, 같은 쪽 중복 1건 제기를 테스트로 통과했습니다.
