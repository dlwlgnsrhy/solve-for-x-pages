AI Brief Kit

위시켓·크몽 제안 쓰기에 매 건 1~2시간을 쓰지만, 500만 원 미만의 건은 수수료 20%에 소모 경쟁이라 아예 안 쓰는 게 이득인 경우도 구분하지 못하는 문제

지금 상태
공개 데모 라이브 · 지금 열 수 있습니다위시켓 건의 제목+금액으로 분류·수수료 구간·접근법 3항목·1페이지 제안 초안을 만드는 규칙 기반 프로토타입을 샘플 데이터로 확인할 수 있습니다. 지금 https://www.solve-for-x.net/demos/ai-brief 에서 데모를 열 수 있습니다.

누구를 위해, 어떻게

이 제품을 찾는 사람
위시켓·크몽에서 수주 활동을 하는 개발 에이전시·프리랜서 팀
처음부터 신경 쓴 점
LLM을 쓰지 않는 결정적 규칙 프로토타입이며, LLM 기반 자연어 제안 생성이나 실제 위시켓 API 연결은 포함하지 않습니다. LLM 도입 여부는 별도 사람 결정 사항입니다.
고른 해결 방법
제목에서 카테고리(우선순위 ERP>연동>BI>EC>AI)를 분류하고, 금액으로 수수료 구간(10/15/20%)을 정한 뒤 접근법 3항목과 1페이지 마크다운 초안을 생성합니다. 20% 구간이면 NO-BID 경고를 함께 냅니다.

만든 것

  • 키워드 규칙 5종 카테고리 분류(우선순위 확정)
  • 수수료 구간 3단(10/15/20%) + NO-BID 경고
  • 카테고리별 접근법 3항목 템플릿
  • 1페이지 제안 마크다운 생성(동일 입력=동일 출력)

확인한 것

공개 사이트에서 데모와 사례 페이지를 볼 수 있으며, 샘플 산출 파일을 내려받을 수 있습니다.

  1. 확인됨

    분류·구간 정확성

    샘플 3건이 10%/15%/20% 수수료 구간과 각각 연동/AI/BI로 분류되는 것을 테스트로 통과했습니다.

  2. 확인됨

    NO-BID 경고

    20% 구간 초안에 NO-BID 경고 줄이 포함되는 것을 테스트로 통과했습니다.

  3. 확인 중

    LLM 활용 범위

    이 프로토타입은 LLM을 사용하지 않습니다. LLM 기반 제안 생성은 아직 검토하지 않았습니다.

화면

쓰기 전에 알아 둘 점

가상의 프로젝트 제목·금액만 사용합니다. 실제 클라이언트 건, 응모 이력, 제안 원문은 데모에 포함하지 않습니다.

  • 키워드 매칭 규칙 기반이라 제목이 애매한 건은 ‘기타’로 분류됩니다 — 실제 위시كت API 연동과 제안 채택률은 검증하지 않았습니다.
  • LLM을 붙이는 순간 출력 검증·비용 경계가 새로 필요해져, 이 부분은 사람 결정 영역으로 둡니다.
