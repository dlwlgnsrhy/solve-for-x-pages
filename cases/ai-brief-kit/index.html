AI Brief Kit

위시켓·크몽 제안 쓰기에 매 건 1~2시간을 쓰지만, 500만 원 미만의 건은 수수료 20%에 소모 경쟁이라 아예 안 쓰는 게 이득인 경우도 구분하지 못하는 문제

현재 상태 · 공개 배포 완료 · 라이브 데모 확인됨
공개 데모 라이브 · 지금 열 수 있습니다

위시켓 건의 제목+금액으로 분류·수수료 구간·접근법 3항목·1페이지 제안 초안을 만드는 규칙 기반 프로토타입을 샘플 데이터로 확인할 수 있습니다. 지금 https://www.solve-for-x.net/demos/ai-brief 에서 데모를 열 수 있습니다.

어떤 사람을 위해 만들었나요?

이 제품을 찾는 사람: 위시켓·크몽에서 수주 활동을 하는 개발 에이전시·프리랜서 팀

처음부터 신경 쓴 점: LLM을 쓰지 않는 결정적 규칙 프로토타입이며, LLM 기반 자연어 제안 생성이나 실제 위시켓 API 연결은 포함하지 않습니다. LLM 도입 여부는 별도 사람 결정 사항입니다.

우리가 고른 해결 방법: 제목에서 카테고리(우선순위 ERP>연동>BI>EC>AI)를 분류하고, 금액으로 수수료 구간(10/15/20%)을 정한 뒤 접근법 3항목과 1페이지 마크다운 초안을 생성합니다. 20% 구간이면 NO-BID 경고를 함께 냅니다.

무엇을 만들었나요?

  • 키워드 규칙 5종 카테고리 분류(우선순위 확정)
  • 수수료 구간 3단(10/15/20%) + NO-BID 경고
  • 카테고리별 접근법 3항목 템플릿
  • 1페이지 제안 마크다운 생성(동일 입력=동일 출력)

LLM 활용 범위

사용 전에 알아둘 점

가상의 프로젝트 제목·금액만 사용합니다. 실제 클라이언트 건, 응모 이력, 제안 원문은 데모에 포함하지 않습니다.

  • 키워드 매칭 규칙 기반이라 제목이 애매한 건은 ‘기타’로 분류됩니다 — 실제 위시كت API 연동과 제안 채택률은 검증하지 않았습니다.
  • LLM을 붙이는 순간 출력 검증·비용 경계가 새로 필요해져, 이 부분은 사람 결정 영역으로 둡니다.
