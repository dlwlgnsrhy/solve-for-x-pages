CSV Validator Web Service

엑셀로 열기 전 ‘이 파일에 내가 보지 못한 문제가 숨어 있는가’를 눈으로 전수 검수해야 하는 문제

지금 상태
공개 데모에서 직접 올린 파일로 확인 가능어떤 CSV든 규칙 설정 없이 올리면 중복 행, 열당 형식 혼합, 합계 행 불일치, 금액 열의 음수, 빈 셀을 브라우저 안에서 자동 감사합니다. 문제만 골라 행 번호와 근거까지 보여 줍니다. 파일은 서버로 전송되지 않습니다.
단계
브라우저 자동 감사 도구 · 공개 데모에서 확인
직접 확인
내 CSV로 자동 감사 돌려보기 ↗

누구를 위해, 어떻게

이 제품을 찾는 사람
정산·입력·대역 이전 파일을 처리하는 운영·회계·데이터 팀
처음부터 신경 쓴 점
실제 데이터베이스 연동 없이 내 파일로 검증해야 하고, 점검 규칙을 사용자가 설정하는 UI나 규칙 CSV 없이 동작해야 하며, 샘플 결과를 고객 성과로 말하지 않습니다.
고른 해결 방법
업로드된 CSV를 브라우저 안에서만 파싱해 범용 패턴으로 5가지를 자동 점검합니다: 행 전체 중복, 열당 값 형태(숫자·날짜·텍스트) 혼합, “합계/total” 행의 수치 재계산, 금액 계열 열의 음수, 빈 셀과 전체 빈 열. 판정마다 행 번호·열 이름·차이를 함께 기록합니다.

만든 것

  • 브라우저 전용 zero-config CSV 감사기(서버 전송 0)
  • 중복 행·형식 혼합·합계 불일치·음수·빈값 5점검
  • 판정 근거(행 번호·열·차이) 기록
  • 감사 결과 CSV 다운로드

확인한 것

공개 사이트에서 데모를 열고, 내 CSV를 올려 자동 감사를 돌려본 뒤 감사 결과 CSV를 내려받을 수 있습니다.

  1. 확인됨

    직접 파일 왕복

    샘플 입력 CSV 7행을 올리면 중복 1, 형식 혼합, 합계 불일치 2(차이 표시), 음수 1건을 찾아내는 것을 테스트로 통과했습니다.

  2. 확인됨

    합계 재계산

    합계 행이 있으면 데이터 합과 비교해 차이까지 보여주는 것을, 일치하는 파일에서는 0건으로 판정하는 것을 테스트로 통과했습니다.

  3. 확인됨

    전체 빈 열 감지

    모든 행이 비어 있는 열을 별도 이슈로 표시하는 것을 테스트로 통과했습니다.

  4. 확인 중

    고객 성과

    실제 고객의 전수 검수 시간 단축은 아직 측정하지 않았습니다.

화면

쓰기 전에 알아 둘 점

올린 CSV는 이 브라우저 안에서만 처리되어 서버로 전송되지 않습니다. 공개 데모의 샘플은 날짜·품목·수량·금액만 사용하는 가상 데이터입니다.

  • 점검은 범용 패턴 기반이며, 도메인 규칙(예: ‘이 코드는 이 값만 허용’)을 설정하는 UI나 규칙 CSV를 제공하지 않습니다 — 계획의 ‘UI 또는 규칙 CSV’ 방식 대신 zero-config 자동 감정으로 단순화한 것을 고지합니다.
  • “합계 불일치”와 같은 판정은 자동 감지가 아니라 사람 확인을 전제로 표시됩니다.
  • 브라우저에서 파일 하나를 올리는 검증 도구이며, 실제 데이터베이스 연동·수만 행 이상 파일 처리량은 검증하지 않았습니다.
