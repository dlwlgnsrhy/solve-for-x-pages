웹 서비스

Two File Reconcile Web Service

두 시스템이 같은 일을 말했다고 해도 한 건 한 건 정말로 같은 금액인지, 한쪽에만 있는 행이 있는지를 전수 대조해야 하는 문제

현재 상태 · 브라우저 대조 도구 · 공개 데모에서 확인
공개 데모에서 직접 올린 파일로 확인 가능

A·B 두 시스템의 내보내기를 소스(A/B)·공통 키·금액 세 열로 하나의 CSV로 합쳐 올리면, 공통 키 조인으로 일치·값 불일치(차이 표시)·A에만·B에만 존재를 골라내고 총액 차이와 순서 무관 체크섬을 브라우저 안에서 보여 줍니다. 파일은 서버로 전송되지 않습니다.

어떤 사람을 위해 만들었나요?

이 제품을 찾는 사람: 정산·재고·주문 데이터를 두 시스템 사이에서 오가는 운영·회계·데이터 팀

처음부터 신경 쓴 점: 실제 두 시스템의 실시간 연동 없이 내 파일로 검증해야 하고, 각 시스템의 코드·상태 도메인을 사전에 설정하지 않으며, 샘플 결과를 고객 성과로 말하지 않습니다.

우리가 고른 해결 방법: 소스 열(A/B)·공통 키·금액을 가진 단일 CSV를 브라우저 안에서만 파싱해 공통 키로 조인합니다. 값이 같은 행은 일치로, 다른 행은 차이까지 표시된 값 불일치로, 한쪽에만 있는 행은 A만/B만으로 나눕니다. 같은 쪽 안에서 키가 중복되면 첫 행만 집계해 중복임을 표시하고, 일치 행으로 순서 무관 체크섬을 계산해 대조 결과를 CSV로 내보냅니다.

무엇을 만들었나요?

  • 브라우저 전용 A/B 대조기(서버 전송 0)
  • 공통 키 조인으로 일치·값 불일치(차이)·A만·B만 분류
  • 총액 차이와 순서 무관 체크섬
  • 대조 결과 CSV 다운로드

지금 확인할 수 있는 것

공개 사이트에서 데모를 열고, 두 시스템의 내보내기를 합친 CSV를 올려 대조를 돌려본 뒤 대조 결과 CSV를 내려받을 수 있습니다.

확인됨

직접 파일 왕복

샘플 입력 CSV 8행을 올리면 일치 1, 값 불일치 1(차이 20,000원), A만 1, B만 1, 같은 쪽 중복 1건 제기를 테스트로 통과했습니다.

공개 화면이나 연결된 페이지를 실제로 확인한 내용입니다.

총액 차이 계산

샘플에서 총액 A 450,000원 / B 580,000원(차이 -130,000원)을 판정하는 것을 테스트로 통과했습니다.

공개 화면이나 연결된 페이지를 실제로 확인한 내용입니다.

사용 전에 알아둘 점

올린 CSV는 이 브라우저 안에서만 처리되어 서버로 전송되지 않습니다. 공개 데모의 샘플은 키·금액만 사용하는 가상 데이터입니다.

  • 두 쪽 중 어느 쪽이 옳은지는 판정하지 않습니다 — 값이 다른 행을 골라 사람이 결정해야 할 곳만 표시하는 도구입니다.
  • 소스(A/B)·공통 키·금액 세 열이 없는 파일은 받아들이지 않으며, 각 시스템의 상태·코드 도메인을 사전에 설정하지 않습니다.
  • 브라우저에서 파일 하나(두 쪽을 합친 형태)를 올리는 검증 도구이며, 실제 두 시스템의 실시간 연동·연동 스케줄과 수만 행 이상 파일 처리량은 검증하지 않았습니다.
