쇼핑몰 주문을 다른 시스템으로 넘길 때 상태코드 체계가 시스템마다 달라 사람이 매번 번역해야 하고, 중복 재전송이 주문을 두 번 기록하게 만드는 문제

현재 상태 · 브라우저 직접 파일 실행 기능 반영 · 공개 데모에서 확인
공개 데모에서 직접 올린 파일로 확인 가능

내 쇼핑몰·발주 시스템에서 내보낸 주문 CSV를 올리면 정상 주문 보존, 중복 주문 멱등 제외, 상태값 누락·금액 오류 행을 브라우저 안에서 확인합니다. 파일은 서버로 전송되지 않습니다.

어떤 사람을 위해 만들었나요?

이 제품을 찾는 사람: 쇼핑몰 주문 데이터를 발주·물류·ERP로 넘기는 운영·CS·물류 팀

처음부터 신경 쓴 점: 특정 쇼핑몰의 스토어 접속 없이 내 파일로 검증해야 하고, 상태코드를 고정 매핑에 종속시키며 샘플 결과를 고객 성과로 말하지 않습니다.

우리가 고른 해결 방법: 업로드된 주문 CSV를 브라우저 안에서만 파싱해, 주문번호 멱등 키로 중복을 거르고 상태값·금액의 구조적 오류만 분리합니다. 상태코드는 파일에 등장하는 값을 그대로 받아 분포로 보여 주어, 내 시스템의 코드로도 동작합니다.

무엇을 만들었나요?

  • 브라우저 전용 주문 CSV 동기화 검증기(서버 전송 0)
  • 주문번호 멱등 키와 중복 주문 자동 제외
  • 상태값 분포 리포트(내 코드로 그대로)
  • 결과 CSV 다운로드(행별 판정·원인)

지금 확인할 수 있는 것

공개 사이트에서 데모를 열고, 내 주문 파일을 올려 돌려본 뒤 결과 CSV를 내려받을 수 있습니다.

제품 화면

실제 제품에서 확인할 수 있는 화면을 공개합니다. 화면에 없는 기능이나 결과를 대신 약속하지 않습니다.

사용 전에 알아둘 점

올린 CSV는 이 브라우저 안에서만 처리되어 서버로 전송되지 않습니다. 공개 데모의 샘플은 주문 번호·상태값·금액만 사용하는 가상 데이터입니다.

  • 브라우저에서 파일 하나를 올리는 검증 도구이며, 실제 쇼핑몰 스토어·웹훅·운영 처리량은 검증하지 않았습니다.
  • 상태코드는 파일의 값을 그대로 보고, 그 코드가 내 업무에서 ‘정상’인지의 판단은 사용자가 합니다.
  • 카페24 플랜별 API 차이, 실제 주문 데이터 규모는 유료 진단 뒤 고객 데이터로 별도 검증합니다.
