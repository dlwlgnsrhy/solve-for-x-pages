Integration Reliability Kit

외부 시스템 연동은 정상 건만 처리하는 것으로 끝나지 않습니다. 일부 행이 실패해도 정상 행을 보존하고, 실패 원인을 남긴 뒤 수정된 한 건만 재처리해야 합니다.

2. 수정 후 수동 재처리

잘못된 계정 매핑을 수정한 한 건만 재처리했습니다. 상태는 완료, 처리 합계는 320,000원입니다.

3. 중복 입력 보호

이미 처리한 외부 ID를 다시 보냈을 때 새 레코드를 만들지 않았습니다. 중복 키 ERP:INV-001를 건너뛰었습니다.

4. POS·SCM → BI 적용 시나리오

POS 매출과 SCM 재고 이동 3건을 API 입력으로 정규화했습니다. 정상 2건은 보존하고, 매핑이 없는 SCM 1건만 실패 로그에 남긴 뒤 수정·재처리했습니다.
