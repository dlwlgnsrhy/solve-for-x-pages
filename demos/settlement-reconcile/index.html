정산 대조 도구 (내 파일로 확인)

정산 대사

플랫폼 정산서가 내 기록과 한 건 한 건 정말로 같은지는 대조할 때만 확인됩니다. 정산서와 내 기록을 두 파일로(각각 열을 직접 매핑) 올리거나, “소스” 열을 달아 합친 한 파일로올려 “정산서에 없는 것, 내 기록에 없는 것, 같은 키인데 값이 다른 것, 같은 쪽에서 두 번 나타난 것”을 골라 보여 줍니다. 파일은 이 브라우저 안에서만 읽히고 서버로 전송되지 않습니다.

어떻게 대조합니까

  • 두 파일(기본): 각 파일을 1개씩 올려 날짜·금액 열을 직접 지정하면 — 날짜·금액으로 5단계 대조(전일치 → 정산 주기 이동 → 수수료 차감 → 미분류 → 누락)를 돌려 원인까지 표시합니다. 엑셀에서 인코딩(EUC-KR)을 바꿔 저장한 한국 실무 파일도 인코딩 자동 감지로 그대로 됩니다.
  • 한 파일(편의): 두 파일을 “소스” 열(정산서/주문 같은 두 쪽의 실제 이름)로 합쳐 올리면 공통 키로 조인해 일치, 값 불일치(차이까지 표시), 한쪽에만 존재(미정산·무근거정산 후보)로 분류합니다.
  • 같은 쪽 안에서 키(또는 날짜·금액)가 두 번 이상 나타나면 중복정산 신호로 표시합니다 — 총액에는 모두 합산된 채로, 그래서 차이에 그대로 드러납니다.
  • 수수료 열이 있으면 키별 수수료 차이까지, 날짜 열이 있으면 정산-발주 일차 분포(최소~최대·중간)까지 보고합니다. 임계값은 두지 않습니다 — 숫자만 보이고 판단은 사람에게 있습니다.

내 파일로 대조해 보세요

플랫폼 정산서(또는 은행 입출금)와 내 기록을 각 1개씩 올려 날짜·금액 열을 지정하세요. 두 파일이 준비되면 즉시 대조하고, 결과가 브라우저 안에서만 표시됩니다 — 파일이 서버로 전송되지 않습니다. 형식이 궁금하면 샘플 은행 내역·샘플 정산 내역(EUC-KR)을 내려받아 그대로 올려 보세요.

파일 1 — 정산서 / 은행 측

CSV를 이 칸에 놓거나 파일을 선택하세요 — 인코딩은 자동으로 감지됩니다.

파일 2 — 내 기록 측

CSV를 이 칸에 놓거나 파일을 선택하세요 — 인코딩은 자동으로 감지됩니다.

파일 1을 올리면 날짜·금액 열을 자동으로 골라 놓습니다.

파일 2를 올리면 날짜·금액 열을 자동으로 골라 놓습니다.

이것이 주는 가치

  • “이번 달 정산이 안 맞는 것 같은데”라는 감각이, 어느 키가 얼마 차이인지, 몇 건이 누락됐는지로 바뀝니다.
  • 중복정산 신호는 총액 차이에서 스스로 드러나도록 설계했습니다 — 따로 계산할 필요 없습니다.
  • 일차 분포가 보이면 “정산이 늦다”는 말이 평균·분산으로 바뀌어, 상대와 같은 언어로 이야기합니다.

이 데모가 증명하지 않는 것

브라우저에서 두 파일(각각 열 매핑) 또는 파일 하나(두 쪽을 합친 형태)를 올리는 검증 도구입니다. 실제 플랫폼 API와의 정산 연동, 수수료율 규칙 검증(“이 수수료율이 계약과 맞는가”), 정산 주기의 자동 감시, 수만 행 이상 파일 처리량은 아직 검증하지 않았습니다. ‘한쪽에만 존재’·‘중복’·‘미분류’ 판정은 어느 쪽이 옳은지를 알려 주지 않고, 사람이 봐야 할 곳만 골라 보여주는 것입니다.
