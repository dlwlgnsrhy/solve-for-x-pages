두 파일 대조 도구 (내 파일로 확인)

Two File Reconcile

두 시스템이 같은 일을 말했다고 해도, 그 숫자가 한 건 한 건 정말로 같은지는 대조할 때만 확인됩니다. A와 B의 내보내기를 공통 키로 조인해 “같은 키인데 값이 다르고, 한쪽에만 있는 행”을 골라 보여 줍니다.

어떻게 대조합니까

  • 각 행에 소스(A/B) · 공통 키 · 금액 세 열이 있으면 됩니다 — 두 파일을 각 1개씩 내보낸 뒤 소스 열을 달아 합친 형태입니다.
  • 공통 키로 조인해 일치(값 동일), 값 불일치(차이까지 표시), A에만 있음, B에만 있음으로 분류합니다.
  • 같은 쪽 안에서 키가 두 번 나타나면 첫 행만 집계하고 중복임을 표시합니다 — 두 번 반영되는 일이 없습니다.
  • 일치 행으로 순서 무관 체크섬을 계산해, 같은 데이터는 어떤 순서로 와도 같은 값을 냅니다.

두 시스템의 내보내기를 합쳐 올려보세요

A 시스템과 B 시스템에서 각각 내보낸 CSV의 행을 “소스” 열(A/B)을 달아 하나의 파일로 합치면 됩니다 —샘플 입력 CSV가 그 형식입니다. 공통 키로 조인해 일치·값 불일치·A만·B만 존재를 찾고, 총액 차이와 순서 무관 체크섬까지 보여 줍니다.

내 파일로 바로 돌려보기

파일이 서버로 전송되지 않습니다 — 모든 처리가 이 브라우저 안에서 끝납니다.

CSV 파일을 여기에 놓거나

이것이 주는 가치

  • “금액이 안 맞아”라는 말만 오가는 대역에서, 어느 키가 얼마 차이인지 한 화면으로 정리됩니다.
  • 누락 행(한쪽에만 존재)을 먼저 잡으므로, 정산 후 발견하는 일이 아니라 전에 잡습니다.
  • 체크섬이 있으므로, 다시 돌려도 같은 값이 나와야 한다는 것을 기계가 확인합니다.

이 데모가 증명하지 않는 것

브라우저에서 파일 하나(두 쪽을 합친 형태)를 올리는 검증 도구입니다. 실제 두 시스템의 실시간 연동·연동 스케줄, 수만 행 이상 파일 처리량은 아직 검증하지 않았습니다. ‘값 불일치’ 판정은 두 쪽 중 어느 쪽이 옳은지를 알려 주지 않고, 사람이 봐야 할 곳만 골라 보여주는 것입니다.
