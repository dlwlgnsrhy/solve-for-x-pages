자동 감사 도구 (내 파일로 확인)

CSV Validator

엑셀로 열기 전, 이 파일에 내가 보지 못한 문제가 숨어 있는지를 기계가 먼저 봅니다. 규칙을 설정할 필요 없이 어떤 CSV든 올리면 5가지 점검이 자동으로 돌고, 문제만 골라 보여 줍니다.

무엇을 자동 점검합니까

  • 중복 행행 전체가 똑같이 반복된 곳을 행 번호와 함께 찾아 줍니다 — 한 번만 반영되어야 하면 중복입니다.
  • 열당 형식 혼합숫자 열에 글씨가 섞였거나 날짜 열에 라벨이 섞인 곳처럼, 한 열 안에 두 가지 이상의 값 형태가 섞이면 알려 줍니다.
  • 합계 행 불일치“합계/total” 행이 있으면 각 열의 합을 데이터에서 다시 계산해 일치하는지, 어긋나면 차이까지 보여 줍니다.
  • 금액 열의 음수금액·가격·단가 같은 열에 음수가 있으면 정정인지 환불인지 사람 판단이 필요하다는 표시로 행 번호를 함께 보여 줍니다.
  • 빈 셀과 전체 빈 열열별 빈 셀 수를 집계하고, 모든 행이 비어 있는 열은 데이터 누락 가능성으로 표시합니다.

내 CSV를 올려 자동 감사를 돌려보세요

규칙을 설정하지 않아도 됩니다. 어떤 CSV든 올리면 빈 셀, 열당 형식 혼합, 중복 행, 합계 행 불일치, 금액 열의 음수를 자동으로 점검하고 문제만 골라 보여 줍니다.샘플 입력 CSV를 내려받아 그대로 돌려도 됩니다.

CSV 파일을 여기에 놓거나

샘플 CSV 다운로드

이것이 주는 가치

  • 수작업 눈 검수 전에 기계가 먼저 보므로, 사람 눈이 놓치는 중복·합계 어긋남을 놓치지 않습니다.
  • “문제 행”만 따로 골라 보여 줘서, 1,000행을 처음부터 끝까지 훑지 않아도 됩니다.
  • 판정 근거(차이·행 번호·열 이름)가 함께 기록되므로, 누가 봐도 같은 결론으로 검수할 수 있습니다.

이 데모가 증명하지 않는 것

브라우저에서 파일 하나를 올리는 검증 도구입니다. 실제 데이터베이스 연동, 수만 행 이상의 파일, 고객 데이터의 성과 개선은 아직 검증하지 않았습니다. 점검은 범용 패턴 기반의 자동화이며, ‘합계 불일치’와 같은 판정은 사람 확인을 전제로 표시됩니다.
