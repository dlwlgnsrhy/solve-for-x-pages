웹 서비스

CSV Validator Web Service

엑셀로 열기 전 ‘이 파일에 내가 보지 못한 문제가 숨어 있는가’를 눈으로 전수 검수해야 하는 문제

확인됨샘플 입력 CSV 7행을 올리면 중복 1, 형식 혼합, 합계 불일치 2(차이 표시), 음수 1건을 찾아내는 것을 테스트로 통과했습니다.
확인됨합계 행이 있으면 데이터 합과 비교해 차이까지 보여주는 것을, 일치하는 파일에서는 0건으로 판정하는 것을 테스트로 통과했습니다.

자주 묻는 질문

문의 전에 가장 많이 묻는 것들.

가격은 어떻게 정해지나요?

신규 접수 시작 가격은 개인형 파일럿 990,000원~, 공유형 프로토타입 1,990,000원~, AI 연결형 프로토타입 2,990,000원~입니다. 먼저 무료 적합성 확인으로 고정 범위를 확인하며, 확인되지 않은 범위를 미리 청구하지 않습니다.

제작까지 얼마나 걸리나요?

가장 중요한 한 장면을 기준으로 1~2주 단위로 만들고 실제 사용을 확인한 뒤 다음 범위를 결정합니다. 처음부터 큰 시스템을 약속하지 않습니다.

앱 스토어 출시도 가능한가요?

가능하지만 기본 패키지에는 포함하지 않고 별도 견적합니다. 스토어 심사 일정과 승인 여부는 각 스토어 정책과 검토 결과에 따릅니다.

만들어진 앱의 소유권은 누구에게 있나요?

전달이 완료되면 고객에게 있습니다. 소스 코드와 스토어 계정 이관 범위는 제안 단계에서 함께 명시합니다.

개인 정보와 기록은 어떻게 보호되나요?

공개 사례에 고객 정보·개인 기록·내부 운영 로그를 넣지 않습니다. AI가 포함된 제품은 실제 가용성·비용·품질을 별도로 검증한 뒤 안내합니다.

제작 중 수정은 몇 번까지 가능한가요?

범위 안에서의 조정은 제작 과정에 포함됩니다. 범위 밖 요청은 다음 범위로 나누어 제안합니다 — 확인되지 않은 작업을 몰래 포함하지 않습니다.

마음에 들지 않으면 환불되나요?

단계별 환불 정책이 있습니다. 착수 전 전액, 제작 착수 후에는 진행된 단계만 정산하는 방식이며, 제안서에 해당 케이스 기준을 명시합니다.

서버·AI 사용 비용은 별도인가요?

AI가 포함된 제품은 월 예상 사용 비용을 검증한 뒤 함께 안내합니다. 서버가 필요 없는 개인형 구성이면 서버 비용이 발생하지 않습니다.
